# Stats TikTok (Windows et Mac)

Les stats TikTok Studio de ton compte, heure par heure, dans une page sur ton ordinateur.
Lecture seule : l'outil ne poste rien et n'envoie tes chiffres nulle part.

**Installer :** télécharge [le zip](../../archive/refs/heads/main.zip), dézippe-le, puis lis `LISEZ-MOI.txt`.
L'outil se met à jour tout seul à chaque lancement.
